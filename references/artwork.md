# Artwork

The cover and four animation frames were made with the built-in OpenAI image generation tool. The GIF is a format conversion of the four generated frames, read left to right and then top to bottom, with a reverse return for a gentle loop. It is decorative artwork, not a product screenshot or evidence of indexing.

## Cover prompt

Create a charming small open-source GitHub project cover illustration. Wide landscape 3:2 composition, polished whimsical hand-drawn editorial gouache and colored pencil on warm cream paper, soft texture, peach orange, sage green, muted sky blue, deep charcoal line work. Theme: a tiny friendly orange cloud-shaped delivery boat floats gently through a pale blue sky-garden, carrying a little browser window with a flourishing green sprout inside. Off to the right a quaint miniature lighthouse with a magnifying-glass shaped lamp looks out over the sky. A tiny friendly square robot helps deliver the little website. Several tiny wildflowers and drifting leaves, lots of comfortable negative space, sweet but not babyish, no people, no photography, no shiny 3D. Carefully render ONLY these two lines of English text in large clear handwritten typography in the upper left: 'Tiny Ship & Search' and below in smaller letters 'A small skill for personal websites'. This is a metaphorical illustration, not an instructional diagram. No logos, no Cloudflare or Google official marks, no status checkmarks implying guaranteed indexing, no other text. Make it beautiful and legible as a GitHub README cover.

## Animation prompt

Use the reference image only as a character and style reference. Create an animation sprite sheet for a small looping GitHub GIF. The output is exactly a 2 by 2 grid of FOUR equal rectangular frames, no borders, no gutters, no text. Landscape entire canvas 3:2 aspect ratio, so each frame is also 3:2. Every frame has the exact same fixed camera and pale cream paper background, minimal hand-painted gouache and colored pencil style. Show only the tiny smiling orange cloud-shaped boat carrying a small browser window with a green sprout and the same little square cream robot from the reference. The boat is small enough to fit entirely in each frame with a generous clean margin. Keep subject scale, appearance and centered position very consistent across all four frames. Frame 1 top left: boat level, robot holding parcel. Frame 2 top right: boat floats 2 percent upward, robot raises one arm slightly, leaves drift a little. Frame 3 bottom left: boat level, robot waves. Frame 4 bottom right: boat floats 2 percent downward, robot lowers arm. A few tiny soft sky swirls under the boat only. No lighthouse, no islands, no scenery, no labels or numbers. This is a cohesive four-frame subtle bobbing and waving cycle to be sliced in reading order. Preserve the cozy charming orange cloud boat design and happy small robot.
